# TuneQuest

TuneQuest is a standalone Twitch chat song guessing game.

It is completely separate from the Twitch RPG project.

## Build

Build 0.0.3

## Game Concept

TuneQuest is a Hangman-style song guessing game.

There is no audio playback.

When a round begins, the song title is completely hidden.

Every few seconds, TuneQuest reveals another unique letter.

If the same letter appears multiple times in the title, every occurrence is revealed simultaneously.

The order of revealed letters is randomized.

Players guess the complete song title through Twitch chat.

The game continues until somebody correctly guesses the song or the round timer expires.
